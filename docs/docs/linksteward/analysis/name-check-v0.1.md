# Name Check v0.1

## Ergebnis

`LinkSteward` sollte nur als interner Arbeitstitel verwendet werden.

## Grund

Der Name `LinkSteward` wird bereits für eine Bookmark-/Lesezeichen-App im iOS App Store verwendet. Da die bestehende App thematisch nah ist, wäre der Name als finaler Produktname ungünstig.

## Empfehlung

```text
Jetzt:
LinkSteward als Codename / Arbeitstitel verwenden

Vor öffentlichem Release:
neuen finalen Namen wählen
```

## Nicht final verwenden für

```text
├─ App-Store-Eintrag
├─ Domain
├─ Logo
├─ Docker Namespace
├─ öffentliches Marketing
├─ Markenauftritt
└─ finale Produktkommunikation
```
