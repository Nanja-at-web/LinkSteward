# ADR – Ollama als lokaler KI-Standard

## Status

Accepted

## Entscheidung

Ollama lokal ist der Standard-KI-Anbieter.

## Konsequenzen

### Vorteile

- Daten bleiben lokal
- keine Cloud-Pflicht
- Homelab-passend

### Nachteile

- Ressourcenbedarf
- Modellqualität unterschiedlich

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
