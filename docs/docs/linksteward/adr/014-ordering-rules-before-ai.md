# ADR – Domain-/Regel-Logik vor KI

## Status

Accepted

## Entscheidung

Regeln und Domainlogik laufen vor KI-Vorschlägen.

## Konsequenzen

### Vorteile

- erklärbar
- funktioniert ohne KI

### Nachteile

- Regelengine nötig

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
