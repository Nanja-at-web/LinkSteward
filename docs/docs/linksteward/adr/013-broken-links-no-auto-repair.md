# ADR – Broken Links nicht automatisch reparieren

## Status

Accepted

## Entscheidung

Broken Links werden markiert, Reparaturen nur nach Bestätigung.

## Konsequenzen

### Vorteile

- kontrolliert
- Original-URL bleibt erhalten

### Nachteile

- mehr manuelle Bestätigung

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
