# ADR – LinkSteward-Erweiterungsschicht

## Status

Accepted

## Entscheidung

LinkSteward wird als KaraKeep-Fork mit additiver Erweiterungsschicht aufgebaut.

## Konsequenzen

### Vorteile

- weniger Risiko
- bessere Upstream-Kompatibilität
- Module klar getrennt

### Nachteile

- mehr Adapter/Mapping
- mehr Joins möglich

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
