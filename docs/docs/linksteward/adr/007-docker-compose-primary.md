# ADR – Docker Compose als Hauptdeployment

## Status

Accepted

## Entscheidung

Docker Compose ist der primäre offizielle Installationsweg.

## Konsequenzen

### Vorteile

- einfach reproduzierbar
- Self-hosting-freundlich
- Services sauber trennbar

### Nachteile

- Docker nötig
- Ressourcenlimits dokumentieren

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
