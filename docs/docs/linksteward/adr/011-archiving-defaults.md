# ADR – Archivierungsdefaults

## Status

Accepted

## Entscheidung

Standard: Link + Metadaten + Reader-Text + Screenshot. PDF, Single HTML, OCR, Video optional.

## Konsequenzen

### Vorteile

- gute Balance
- Speicher kontrollierbar

### Nachteile

- nicht so vollständig wie Vollarchiv

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
