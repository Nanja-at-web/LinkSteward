# ADR – KaraKeep als technische Basis

## Status

Accepted

## Entscheidung

LinkSteward nutzt KaraKeep als technische Basis.

## Konsequenzen

### Vorteile

- schnellerer Start
- vorhandene Bookmark/List/Tag-Strukturen
- vorhandene Worker/Importer nutzbar

### Nachteile

- Upstream-Abhängigkeit
- Linkwarden-Funktionen müssen ergänzt werden

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
