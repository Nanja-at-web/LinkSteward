# ADR – API-first und Floccus vor eigener Browser Extension

## Status

Accepted

## Entscheidung

Zuerst stabile APIs und Floccus-Support, eigene Extension später.

## Konsequenzen

### Vorteile

- schneller Browser-Sync
- weniger Wartung
- stabile API als Fundament

### Nachteile

- Floccus begrenzt MVP-Funktionen
- Kompatibilität muss exakt getestet werden

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
