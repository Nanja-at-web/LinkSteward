# ADR – Duplikate nie automatisch löschen

## Status

Accepted

## Entscheidung

LinkSteward löscht Duplikate nie automatisch.

## Konsequenzen

### Vorteile

- weniger Datenverlust
- Nutzerkontrolle

### Nachteile

- mehr manuelle Arbeit

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
