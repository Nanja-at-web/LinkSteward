# ADR – KaraKeep-kompatible API im MVP

## Status

Accepted

## Entscheidung

LinkSteward stellt eine KaraKeep-kompatible API bereit.

## Konsequenzen

### Vorteile

- passt zur Basis
- Floccus KaraKeep-Modus
- Migration einfacher

### Nachteile

- doppelte Kompatibilität
- Testaufwand

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
