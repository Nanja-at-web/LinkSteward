# ADR – Linkwarden-kompatible API im MVP

## Status

Accepted

## Entscheidung

LinkSteward stellt eine Linkwarden-kompatible API für Floccus bereit.

## Konsequenzen

### Vorteile

- Floccus Linkwarden-Modus
- Migration einfacher
- passt zu Collections/Links

### Nachteile

- Mapping-Aufwand
- nicht alle Items kompatibel

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
