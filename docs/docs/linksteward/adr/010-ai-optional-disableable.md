# ADR – KI optional und abschaltbar

## Status

Accepted

## Entscheidung

KI ist optional, OpenAI-kompatible API optional, vollständig abschaltbar.

## Konsequenzen

### Vorteile

- Datenschutz
- ressourcenschonend
- Nutzerkontrolle

### Nachteile

- weniger Automatik ohne KI

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
