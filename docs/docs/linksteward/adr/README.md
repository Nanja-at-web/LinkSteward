# LinkSteward – ADRs

ADR = Architecture Decision Record.

Dieses Verzeichnis enthält wichtige Architekturentscheidungen für LinkSteward. Entscheidungen können später geändert werden. Alte ADRs sollten dann als `superseded` markiert und nicht gelöscht werden.

## ADR-Liste

```text
001 – KaraKeep als technische Basis
002 – LinkSteward-Erweiterungsschicht
003 – AGPL-3.0 Open Source
004 – API-first und Floccus vor eigener Browser Extension
005 – Linkwarden-kompatible API im MVP
006 – KaraKeep-kompatible API im MVP
007 – Docker Compose als Hauptdeployment
008 – Proxmox LXC als offizieller Zweitweg
009 – Ollama als lokaler KI-Standard
010 – KI optional und abschaltbar
011 – Archivierungsdefaults
012 – Duplikate nie automatisch löschen
013 – Broken Links nicht automatisch reparieren
014 – Domain-/Regel-Logik vor KI
015 – Soft Delete und SSRF-Schutz
```
