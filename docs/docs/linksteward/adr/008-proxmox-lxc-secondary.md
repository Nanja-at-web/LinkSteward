# ADR – Proxmox LXC als offizieller Zweitweg

## Status

Accepted

## Entscheidung

LinkSteward soll Proxmox-LXC-kompatibel sein.

## Konsequenzen

### Vorteile

- Homelab-freundlich
- Community-Scripts möglich

### Nachteile

- zusätzlicher Wartungsaufwand
- Chromium im LXC kann Sonderfälle haben

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
