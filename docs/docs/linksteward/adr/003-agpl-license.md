# ADR – AGPL-3.0 Open Source

## Status

Accepted

## Entscheidung

LinkSteward wird als AGPL-3.0 Open-Source-Projekt geplant.

## Konsequenzen

### Vorteile

- passt zur Basis
- self-hosting-freundlich
- transparent

### Nachteile

- AGPL-Pflichten bei SaaS
- proprietäre Erweiterungen schwieriger

## Änderbarkeit

Diese Entscheidung kann später ersetzt werden. Dann sollte dieser ADR als `superseded` markiert und auf den neuen ADR verwiesen werden.
