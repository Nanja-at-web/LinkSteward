# Naming

## Status

`LinkSteward` ist aktuell nur ein interner Arbeitstitel / Codename.

## Warum nicht final?

Der Name `LinkSteward` wird bereits von einer Bookmark-/Lesezeichen-App im iOS App Store verwendet. Da der vorhandene Name thematisch nah an diesem Projekt liegt, sollte `LinkSteward` nicht als finaler öffentlicher Produktname verwendet werden.

## Entscheidung

```text
Interner Arbeitstitel:
LinkSteward

Finaler Produktname:
noch offen
```

## Vor öffentlichem Release nötig

Ein finaler Name muss gewählt werden vor:

```text
├─ öffentlichem Release
├─ offizieller Domain
├─ Logo/Branding
├─ App-Store-Einträgen
├─ Docker-Image-Namespace
├─ öffentlichem Marketing
└─ möglicher Markenregistrierung
```

## README-Hinweis

```md
Project codename: LinkSteward

“LinkSteward” is a temporary internal working title and not the final product name.
A final name will be chosen before public release.
```
