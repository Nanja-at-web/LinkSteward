# LinkSteward – MVP Scope v0.1

## MVP-Ziel

Der MVP soll eine nutzbare selbst gehostete App bereitstellen, die Links speichern, archivieren, synchronisieren, organisieren und prüfen kann.

## MVP-Funktionsumfang

```text
LinkSteward MVP
├─ KaraKeep als technische Basis
├─ AGPL-3.0 Open Source
├─ Docker Compose Installation
├─ Proxmox LXC Support
├─ Linkwarden-kompatible API
├─ KaraKeep-kompatible API
├─ Floccus-Support über kompatible APIs
├─ Bookmark HTML Import/Export
├─ Domain- und Themenbaum-Kategorisierung
├─ regelbasierte automatische Sortierung
├─ Ollama Auto-Tagging als lokale KI-Option
├─ Duplikat-Erkennung
├─ Broken-Link-Monitor
└─ Standardarchivierung: Link, Metadaten, Reader-Text, Screenshot
```

## MVP-Akzeptanzkriterien

```text
MVP erfüllt, wenn:
├─ LinkSteward per Docker Compose installierbar ist
├─ Nutzer Links speichern kann
├─ Links Metadaten, Reader-Text und Screenshot erhalten
├─ Collections/Listen und Tags funktionieren
├─ Browser Bookmark HTML importiert wird
├─ Browser Bookmark HTML exportiert wird
├─ Floccus über Linkwarden-kompatible API synchronisiert
├─ Floccus über KaraKeep-kompatible API synchronisiert
├─ Domain-/Themenbaum-Kategorisierung nutzbar ist
├─ Ollama Auto-Tagging optional funktioniert
├─ Duplikate erkannt und gruppiert werden
├─ Duplikate mit Vorschau zusammengeführt werden können
├─ Broken Links erkannt und markiert werden
├─ Reparaturvorschläge angezeigt werden
├─ keine Duplikate automatisch gelöscht werden
├─ keine Broken-Link-Reparatur ohne Bestätigung erfolgt
└─ Proxmox LXC Support mindestens dokumentiert ist
```
