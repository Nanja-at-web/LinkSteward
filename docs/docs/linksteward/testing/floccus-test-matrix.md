# Floccus Test Matrix v0.1

## Browser

```text
├─ Firefox Desktop
├─ Chrome/Chromium Desktop
├─ Edge/Brave/Vivaldi optional
└─ Android/Kiwi später optional
```

## Modi

```text
├─ Linkwarden-Modus
└─ KaraKeep-Modus
```

## Grundtests

```text
├─ Verbindungstest
├─ initialer Sync leere Sammlung
├─ initialer Sync mit vorhandenen Bookmarks
├─ Bookmark erstellen
├─ Bookmark ändern
├─ URL ändern
├─ Bookmark löschen
├─ Ordner erstellen
├─ Ordner umbenennen
├─ Ordner verschieben
├─ Ordner löschen
├─ Bookmark verschieben
├─ parallele Änderung
└─ Konfliktfall
```

## Akzeptanzkriterien MVP

```text
├─ mindestens Firefox + Linkwarden-Modus funktioniert
├─ mindestens Chromium + Linkwarden-Modus funktioniert
├─ KaraKeep-Modus funktioniert grundlegend
├─ Soft Delete bei Löschungen
├─ nicht unterstützte URL-Schemata werden nicht ausgegeben
└─ bekannte Einschränkungen dokumentiert
```
